# Локальные медиа

В `scripts/script.js` включён `DATA_SOURCE = 'local'`. В этом режиме приложение не обращается к API: карточки, поиск и пагинация используют массив `localVideos`, а видео и изображения загружаются из `media/`.

Шесть демонстрационных карточек повторно используют три постера и два видео. Названия городов и время суток условные, они нужны для проверки фильтров и не описывают реальные места съёмки. Первая страница содержит пять карточек; «Показать ещё» добавляет шестую.

Откройте `index.html` через сервер PyCharm. Для поиска подходят: Белгород, Адлер, Воронеж, Зеленоград, Санкт-Петербург и Москва. Несколько отмеченных значений времени суток объединяются по принципу «или», а город и время — «и».

Чтобы вернуть внешний сервис после его восстановления, установите `DATA_SOURCE = 'api'`. Автоматическое переключение при сбое API не включено, чтобы реальные результаты и демонстрационные данные не смешивались.

Если браузер не сможет воспроизвести MP4, прелоадер будет снят по событию ошибки или через пять секунд; постер и стандартные элементы управления видео останутся доступны.
