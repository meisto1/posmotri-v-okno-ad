# Посмотри в окно

Учебный проект: оформление готового приложения по макету с помощью CSS.

## Запуск

Откройте `index.html` через локальный сервер, например встроенный сервер PyCharm.

В `scripts/script.js` включён `DATA_SOURCE = 'local'`: видео и постеры загружаются из `media/`, внешний API не требуется. Поиск, выбор карточек и подгрузка работают на шести демонстрационных записях. Названия городов и время суток условные; три постера и два ролика используются повторно.

Для подключения исходного API после его восстановления измените `DATA_SOURCE` на `'api'`.

## История

HTML, исходный JavaScript, шрифты и вспомогательные стили предоставлены в стартовой заготовке. CSS реализован отдельными последовательными коммитами; затем добавлена поддержка локальных медиа.
